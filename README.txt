HOUSEBETS SPORTSBOOK — CLICKABLE FRONT-END PROTOTYPE

Open index.html in a modern browser. No build step, backend, account, API key or external library is required.

Included pages:
1. Sports home
2. Live
3. Football
4. Match page (Arsenal v Brighton sample)
5. Bet slip + My bets

Interactions:
- Navigate with the left navigation (bottom navigation on phones).
- Tap any price to add a single selection.
- Enter a demo USDT stake and place demo singles.
- Simulate odds changes, suspension, and failed bet feedback.
- Open, settle and view demo bets; cash-out is intentionally unavailable.
- Search sample team and competition names.

Responsive targets: 390px mobile and 1440px desktop.
All data is fictional demonstration data. No real player data, real funds, wallet, payments, live odds or betting backend are connected. Demo USDT has no cash value.

Deployment: Upload the contents of this folder (index.html and README.txt) to a static host such as Netlify Drop, Vercel, or GitHub Pages. The prototype is front-end only.

Brand note: No starter shell or brand-pack files were present in the current conversation or discoverable Library search, so this uses a lightweight dark Housebets-inspired placeholder wordmark and green accent system. Replace those with the supplied official assets when available.
